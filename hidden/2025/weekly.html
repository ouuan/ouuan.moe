真的周记了（

3.31 - 4.6

Neovim v0.11 似乎把一些高亮 break 了，包括我一直用的 hardline，于是终于换到了 lualine；其实早就试过，感觉默认还不如 hardline，但配了一下真香啊。顺便还搞了点别的，以及 blink.cmp 刚好 1.0，也换上了。好久没配这么多 neovim 了；什么时候能告别 vim-plug（

还在继续急救 Saiblo，但懒得写博客了，感觉有点无聊，而且马上要 rebuttal 了，害怕（

突然想起来我那张京东 E 卡，当时拿到就激活了，完全没想过会没机会用（；一方面是淘宝这个省钱卡把原有的价格差距进一步拉大（只不过刚好这周到期了，还想要不要续费，结果“仅平台邀约用户可开通”，有点神秘了），一方面是京东仍然算是有优势的电子产品这块又遇上国补，要国补就不能用 E 卡；现在放了这么久，如果早卖掉可能放余额宝都差不多把差价赚回来了（

想到京东就又想买耳机了，先是想着原来的 Galaxy Buds 2 还能继续用，然后又想到可以搞个延迟低一些的，看了一堆评测，纠结了很久，最终买了个支持 2.4G 连接的。但我又不怎么打游戏，为什么呢（；首先，如果不考虑延迟，感觉 Buds 2 除了降噪稍差其他都还好，没必要换；虽然看个视频不需要 2.4G 的 20ms 延迟，但现在接近 300 还是有一点影响的，而我实在没搞清楚我的电脑软（Linux）硬件到底支持哪些协议编码，就算支持也不知道能不能低延迟（评测一般都只有手机，连 Windows 都没有），如果用蓝牙，搞不好什么耳机都还是 200+ 的延迟，什么 LHDC、LC3 可能都没用，要保证兼容还是 2.4G 靠谱；最后，有了 20ms 延迟是不是能复健一下 Arcaea（

研究了一下蓝牙协议编码以及相关配置的另一个成果是，换上了 Pipewire，于是 Buds 2 能 AAC 了（。搜了一下消息记录，原来上次 wireplumber 替代 pipewire-media-session 挂掉都是 2022 年的事了，这么久了还一直没换（

耳机到手之后试了下，2.4G 电脑延迟 100 出头，手机 60 左右，并不 20，不知道是哪里的问题，但也还好，视频够用，如果要音游的话，虽然 60 也很高，但只要稳定就行（所以稳定吗（，以前一下 300 一下 400 的就很寄。手机上看似乎蓝牙只能 SBC / AAC / LDAC，没有 LC3，如果不连 2.4G 就还是 200+ 延迟，稍微拉了点；Linux 就更神秘了，一开始连上后不识别为音频设备，耳机这侧也没有连接成功的提示，试了半天发现，旧耳机是 BR/EDR 连接，新耳机默认是 LE 连接，而 Pipewire 现在的 LE Audio 比较寄，最后在 /etc/bluetooth/main.conf 里设了 ControllerMode = bredr 就可以了。但这就是一个，我可以不连，但你不能连不上，的事情，连上之后就删了（，不然 Linux 上同时连着蓝牙和 2.4G，选择输出还有点麻烦，平时应该主要还是用 2.4G，蓝牙就手机偶尔用用的样子。去问了下客服蓝牙到底能不能 LC3，最后说是兼容问题，等固件更新，我很怀疑（

周末看 Redbud 没人，就跟着 Blue Water 打了 PlaidCTF，被带飞了。上次来还是我独立做出来一题之后临时过来，这是第一次真的一起打，队友又多又强是这样的吗（，就做了两三个题的非常小一部分，也很难说到底有没有贡献（

清明没开组会爽了，但周一咋办，这周怎么都摸过去了（

4.7 - 4.13

周一晚上反复刷 HotCRP、Gmail、清华邮箱、小红书；周二起来一看，1112，这是什么，但是它们好绿（，一看，1 是 Accept，2 是 Accept on Shepherd Approval，我超，怎么会这样（，而且 confidence 是 2323（1 高 4 低），给 2 的 confidence 低，ethics 和 open science 均无问题；我之前的预期是 major revision，至少也得 shepherd 吧（，意见好少，我觉得我有的问题很多都没提，rebuttal 不用一天就能搞定，感觉以后审别人的论文也该更宽容点少写几句（。所以有机会 distinguished 吗，我看 composition kills 都是三个 minor revision 两个 accept（ 还是认真写了 rebuttal，结果导跟我说，分高就得少写点，避免说错话降分（；但是消融实验的初步结果有点难评，很难说 rebuttal 要不要把结果写上（

在小红书上刷到一个今年中了一篇 CCS 和两篇 S&P 的，一搜发现竟然三篇都是一作，太可怕了，但主题怎么有点熟悉，打开唯一一篇现在能看 pdf 的，草，这不是之前我审过的那篇 NDSS 的加强版吗，世界真小（，怀疑是原来那些漏洞包了个新方法，还成功升级到 S&P 了，是不是应该感谢我没 accept（

数设实验开始了，那个路由器同学一开始落单了，选了个比较简单的题目，周一才发现有个同学一直没加群也没组队，结果他们组上之后也没换题目，疑似有点水了（；和同学交流的时候发现有一组想用姿态传感器，我还真把我的电子垃圾带去了，但是推销失败，没人敢用旧的（？；后来组会听到一个不认识的同学说在准备期中考试，但其实是期末考试，发现是数设，是否说明我们组生源还可以，数设率很高啊（

滚系统的时候发现 dkms 提示 “Missing the module source directory or the symbolic link pointing to it. Manual intervention is required!”，在群里搜了下，这都是不知道为什么遗留下来的，把对应目录删掉就行。看了下 pacman.log 这个 error 半年前就在报了，瞎了半年（

给论文加图的时候终于受不了 Okular (poppler) 窄线消失的问题了，试了下 okular-backend-mupdf，但一下就 crash 了，只好换成了 Zathura + MuPDF。感觉还行，但是缺 smooth scroll 和目录搜索。

周末拼尽全力无法战胜 DEF CON，人太少了；大家是不是有期中（

4.14 - 4.20

周一刚跟导聊完 rebuttal 要怎么改，突然发现之前看错了 reviewer 写的消融目标，虽然之前测的结果难评，但 reviewer 让我做的反而效果可以，感动（

填了一下荣誉学位申请，这个课程成绩要求只有 4.0 数量，没有 GPA，我竟然超额符合（，就是不知道 paper 能不能直接 accept，如果要 shepherd 就赶不上在这个荣誉学位申请的 ddl 前正式 accept 了（

新耳机经常放进充电盒盖上后左耳机没充上电、蓝牙不断连，周二终于受不了给换了。一开始客服说最多要十个工作日，害怕，但又能怎么办呢（；取货之后系统显示周四才会送到售后；结果周三一看，已经送到了，第二天就收到了新的，客服也太保守了。但是新的好像还有这个问题，难绷，只不过触发频率看起来低一些，可能勉强能用吧，过两天要是又受不了了再考虑要不要退掉换个平替，但它除了接触不良别的真的挺好的（；以前似乎没怎么换过货，才知道三包内的质量问题 15 天换货后会刷新时间，又能再来 7 天退货 15 天换货。

在 科技爱好者周刊（第 345 期） 看到 让你的 RSS/Atom feed 更好看，虽然早就知道 RSS 可以加样式，但一直没加，看到这个算是一个提醒，于是去加了一下。也不知道是不是个好设计，但我选择了完全复刻 HTML 界面。本来想着要不要写篇博客，但感觉还是算了，感觉主要是在和 iles 搏斗，再就是复刻样式并使用 UnoCSS，正常人可能用不到（

更新了 konsole 之后发现字体非常奇怪，一看不等宽了。研究了半天，发现 bad commit 是 关了强制 full hinting，中途放弃了去看了一圈 alacritty、wezterm、rio、ghostty、kitty，光看中文字体显示，感觉就只有 kitty 勉强还行，其他都或多或少不太能用，我用了这么多年 konsole 还是有道理的（。还试了下改 KDE 设置调成 medium/full hinting，发现好丑。最后终于发现，在 konsole 里把 complex text layout 的 word mode 关掉就好了，变成 slight hinting 之后也比以前好看了（只不过 archlinuxcn 群友表示，还得是 4K 屏才好（

但是研究这个字体导致最后没时间继续打 b01lers CTF，这次纯一个人打（我也没权限建 Discord channel，每次说了也没什么人来，干脆不说了），名次倒还可以。

虽然 Redbud 的 DEF CON Quals 寄了，但 DEF CON 和 USENIX Security 时间连着，或许还是可以跟着 Blue Water 去试试（如果能有签证的话），但我跟他们熟吗，感觉有点不好意思，或许这几个月多跟他们打几场吧（

DEF CON Quals 有个题我想写个比较详细探究原理的 wp，但发现本地复现不出来当时 remote 的行为，它比赛一结束就访问不了题目了，公开的源码应该是不完整，和 remote 不一样，问 admin 一直不回复，有点难绷。

4.21 - 4.27

这周事情好多，之前那个大模型安全横向几个月没动静现在要做对接，数设 qcb 说不想再发那个祖传十几年的参考代码了想换个新的，我也不想发自己看不懂的代码，就新写了一个还加了点功能，周四被邀请去一个生涯规划分享会，周五良师益友颁奖，写 DEFCON memorybank 的 wp 还发现我之前搞错了得继续研究（

本来想着周末就不打 CTF 了，结果做完 web 和 misc 还忍不住做 pwn，绷不住了，得疯狂赶工了（

4.28 - 5.4

通宵赶工之后，第二天没人找我，后面两天也很佛，五一就放假了，真的很容易混啊（

数设有大班（数电）同学加入，看到眼熟的名字，发现又是组里同学，不懂就问，我们组和数字逻辑有什么关系吗（

USENIX 这次结果出得好早，AoE 还没到 4.30，19:25 就收到邮件了，是直接 accept，感动，该看看怎么办签证了。不知道什么时候能去面签，感觉必然会 check（，希望能抢到 6 月中旬以前的，但又等不到录取通知书了，我该拿个拟录取名单去吗，还是说抢不到放号正好能等到录取通知书，最后正好错过 DEF CON 极限赶上参会（

还发了一下小红书，以及补发了圣地巡礼，比较难过的是，其他几个包括将棋会馆都有人点赞，唯独月岛没有，怎么能这样（

有了论文，似乎应该弄个 academic homepage。还是不想用模板，自己糊了一个，用 Vue 但是纯 SSG 无交互，Vue 还是好用的，越写越觉得幸好没想不开用 Hugo 之类的（

首先是弄一个新域名，academic homepage 还是正式规范点比较好，就 yufanyou.com 了。搜了一下大家推荐在哪买域名，很多人都推荐 porkbun，看了下确实不错，而且好便宜，前几年没用血亏，把 ouuan.moe 也 transfer 了。

然后是，很久没开新前端项目了，之前一直搁置着，这次终于把 ESLint config 升级到了 flat config，这个设计确实比以前好，但升级真麻烦啊，我们前端是这样的，还是看看隔壁优雅的语法和不用配置的 rustfmt 和 clippy 吧（

再就是，上周去讲座还没放露脸照片，主页似乎不得不放了（，看了下，我好像唯一一张比较能看的照片是 SECCON 颁奖，网上那张还很糊，但幸好主办方之前在 Discord 上私发了几张高清的。

认真设计好每个细节后，五一就过去了一大半，唉，到底为什么要看半天多一个像素好还是少一个像素好，不如看看半个月前写的 XSLT，似乎还没一个人点进去看过（

5.5 - 5.11

在小红书看到 USENIX 的直接接收率不足 1%，和 distinguished 率差不多，而看到别人唯一一个直接 accept 的还是 2223，期待（害怕（

因为同时参加竞赛和会议 + 本科毕业暑假不是在校生 + 去的是美国 + 不是跟团要我自己 DIY + 但是又涉及到 Redbud 和 Blue Water 两支战队，把各种老师同学问了个遍，感觉陷入了规则怪谈，社交过载了（，并且因为事情太多，弄完之后还总觉得没弄完，焦虑（

之前看到说周四 11:00 面签放号，于是准点进去看到没号，失望退出，结果过了一会儿在厕所里看到放号监测服务号的通知，飞奔回来抢到了 6.4 的号，但其实 6min 才没（比抢课慢（，后面还接着放了 6.5 和 6.6 的号，没得更慢，只不过这后两天应该是毕设答辩，6.4 还是好一些。

蓝莲花十五周年论坛从 4.26 延期到 5.10，智能体决赛从 4.27 延期到 5.10，Midnight Sun CTF Quals 从 4.26 延期到 5.3 然后延期到 5.10；但是，智能体又延期到了 5.11，Midnight 又延期到了 5.17，于是它们又错开了（

结果这个智能体决赛，最后 1h 还在补测，临时开结果竞猜，主持人开自动模式，不知道竞猜抽奖什么时候开始结束，奖品比人多，到场只有三个外部人员变成智能体部团建+瓜分周边，绷不住了（

5.12 - 5.18

终于收到了 SECCON 的报销，保险还是报了全额，感动（

在水群看到 zyj 在问小学期安排，去问了下，才得知今年已经有 zyj 和 yxy 来当 Rust 助教了，只不过杰哥和 harry 退休了，问了下 hwt，说等出差回来再商量要不要我来；突然一下换掉所有助教的话感觉是有点可怕的，而大家甚至还在讨论换大作业，虽然我也觉得是该换了，但都刚上任的话就先别换了吧（

那个一年三篇四大一作的复旦哥，这次 S&P 还拿了个 distinguished paper。顺便去问了下才知道，那篇投 NDSS 的不是他的，又看了下，确实方法完全不同，只是测试对象差不多，但也不完全一样。

之前 rebuttal 的时候，我发现我的 PC conflicts 只剩四个人了，还害怕了一阵子，生怕是当时临近 ddl 操作匆忙漏填了，甚至怀疑这背后会不会有什么神秘 py，或者我分这么高是不是 lq 给的。现在才发现，原来是有几个人在 cycle 2 突然不当 PC 了，终于放心了（那么这背后又有什么故事呢（，反正就算有什么瓜只要主角不是我就好（

这周面签放了好多号，还有不少 5 月的，幸好之前抢到的也还算早，如果抢到个十几号的这周都不知道要不要重新约。

虽然横向突然多了个活，但毕设查重推迟了三天，好（；但是答辩变成了 6.4 前，不会要面签完就去答辩吧（

周一晚上看到我妈小红书给月岛点了个赞，震惊之余想了想这应当是意料之中会发生的事情（，但是周一就单点这一个，周二才点了 accept，怎么会是呢。最神奇的是，周六我爸妈刚好有事来北京吃了个饭，我说我要去开会的时候，我妈一副啥都不知道非常惊讶的样子，如果是装的还挺厉害的（？

在小红书上刷到说去日本不要一次东西都去，除非这辈子只去一次日本，不然交通不划算；普通旅行还只是单程，而如果是 SECCON 学校报销的话，想去京都就得三天内比赛之余来回一趟，虽然不是不可能但实在逆天（，于是去查了一下，虽然现在现实中新人战一般是 10 月，但根据 58 话标题「梅雨の始まり」以及后续 83 话中出现的日期 7.28，可以确认修学旅行是在 6-7 月（为啥要管这个），7 月我应该（或许）相对没啥事，而机票从 7.21 这周起会比之前贵一档，如果从上海走会便宜一点，再一看 BW/BML 正好是 7.11-13，那么现在的问题就是能不能一个月内结束 check 并且抢到票，以及什么时候搬寝室（。要是真行的话，突然想去 金阁寺北野天满宫岚山清水寺平安神宫新京极鸭川银阁寺京都塔 体验一下修学旅行（本来还想着似乎除了鸭川也没哪想去，不如看看半年后的虹咲完结篇二去了哪，但翻 3 狮的时候才想起来其实是可以按修学旅行路线来的，虽然出现在剧情中的只有新京极鸭川这里，但其余部分怎么就不是体验ひなた心路历程的圣地了呢（。为什么突然开始幻想了，所以 check 真能一个月内吗，能之后补交护照吗（也不敢在 check 期间随便离开导致无法即时提交吧），怎么不抢抢月底的面签（

这次 Midnight Sun，因为担心 Redbud 没人，以及这次用的 ID 是 blue-lotus 上不了分，就去隔壁 Water Paddler 打的，没想到隔壁人更少，寄（
